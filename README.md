# CI/CD Quiz Coursework


**Status: Coursework / learning project.**

Coursework exploring Cypress component testing and GitHub Actions deployment pipelines.

Preserved as a learning reference; production deployment and current compatibility have not been verified.

## Repository contents

- React and TypeScript quiz interface
- Express and MongoDB API
- Cypress component tests and fixtures
- Example workflows in `github-sample/`

The workflow files are examples; they are not active GitHub Actions workflows in their current directory. See TECH-QUIZ for the related quiz coursework.

Original coursework materials are retained in the source. Preserve their existing attribution and notices.
